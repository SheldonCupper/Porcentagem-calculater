# Plano de testes: calculadora de porcentagem

- [ ] R$ 100 com acréscimo de 10% = R$ 110.
- [ ] R$ 100 com desconto de 10% = R$ 90.
- [ ] 10% de R$ 100 = R$ 10.
- [ ] R$ 0 e 0%: resultado válido, não erro.
- [ ] Campos vazios: resultado oculto sem erros.
- [ ] Valores negativos e não finitos: informar erro.
- [ ] Valores com casas decimais: revisar arredondamento.
- [ ] Testar celulares, teclado e botão limpar.

Os testes são manuais e precisam de confirmação em navegador antes de tratar o projeto como validado.
